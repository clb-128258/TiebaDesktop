# CLI 启动参数用法

## 任务命令执行次序

本程序的任务性启动参数处理分为三层，具体如下：

1) 第一层负责执行对内部配置有重写性的任务，如重定向用户数据目录，在该层下一次可执行多个参数，且优先级比第二层高。执行后会继续执行下面的任务
2) 第二层负责执行一些具有写入性的命令，如切换账号、清空用户数据等，在该层下一次只能执行一条参数。执行后不会执行下面的第三层任务
3) 第三层负责执行一般指令，如签到等，在该层下一次调用可执行多个参数

> [!note]
>
> 性质为`标记`的启动参数值，不具有实际执行的任务，只起到标记选项开关的作用，可以与任意参数叠加使用。

## 静默执行参数

参数性质：标记  
用法：`--quiet`  

指令执行完成后默认有弹窗提示，如需不显示弹窗而直接结束程序，请添加此参数。

> [!note]
>
> 如果启动时只带 `--quiet` 参数，则软件会进入 GUI 运行模式，并创建系统托盘，在后台静默运行，不弹出主窗口。

## 重定向用户数据目录

参数性质：任务（第一层）  
用法：`--reset-udf --udf-path=YOUR_PATH`  

其中 YOUR_PATH 为你要定向到的用户数据目录。

## 切换账号

参数性质：任务（第二层）  
用法：`--set-current-account --userid=YOUR_UID` 

其中 YOUR_UID 为你的用户 ID，可以在 软件设置-账号切换 中复制出你的用户 ID。

## 卸载时清理用户数据

参数性质：任务（第二层）  
用法：`--uninstall-cleanup`

该参数会结束所有已打开的贴吧桌面进程，并删除相关注册表项，最后弹窗询问用户是否要删除数据，如果是则删除 `datapath` 目录。  
该参数应当在卸载本程序时调用。

## 签到所有关注的吧

参数性质：任务（第三层）  
用法：`--sign-all-forums`  

将签到当前激活账号下关注的所有吧，逻辑与软件内`一键签到`功能相同。

## 成长等级签到

参数性质：任务（第三层）  
用法：`--sign-grows`  

将为当前激活账号执行贴吧的成长等级签到，逻辑与软件内`一键签到`功能相同。
